## סעיף 5: בקרות גישה

|-----------|-----------|--------------|
| **מורה** | תלמידי הכיתות שלו בלבד; לא רואה כיתות מורים אחרים | `teacherId` בכל שאילתת DB; אימות בשכבת ה-Repository |

## סעיף 6: אמצעי אבטחה טכניים

| אמצעי | פירוט |
|-------|-------|
| **הצפנת סיסמאות** | bcrypt, cost factor 12 — חד-כיוונית |
| **מיסוך ת.ז.** | 4 ספרות אחרונות בלבד בכל תגובות API (`*****1234`) |
| **אימות audit בלוגים** | SHA-256 מקוצר (16 תווים) — לא ניתן לשחזור ת.ז. גולמית |
| **תקשורת מאובטחת** | HTTPS/TLS חובה; HSTS בייצור |
| **JWT** | HS256 עם whitelist אלגוריתמים; cookie HttpOnly + SameSite=Strict |
| **כותרות HTTP** | Helmet, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy |
| **Rate Limiting** | כניסת תלמידים: 10/דקה; רענון טוקן: 20/דקה; ייבוא קבצים: 2/דקה |
| **בדיקת סוג קובץ** | ייבוא רשומות: סינון MIME-type (`xlsx`, `csv`) לפני עיבוד |
| **ORM** | כל שאילתות DB דרך Prisma (parameterized) — ללא SQL גולמי |
| **יומן ביקורת** | כל פעולה רגישה נרשמת עם timestamp, actorId, ערך ישן וחדש |

## סעיף 8: העברות מידע בין-לאומיות

| יעד | סוג מידע | מנגנון הגנה |
|-----|---------|------------|
| Google LLC (ארה"ב) | שם + אימייל מורה | Standard Contractual Clauses (SCCs) |
| שרתי ענן (מחוץ לישראל, אם רלוונטי) | כלל נתוני המערכת | DPA + SCCs עם ספק האירוח |

> ישראל מוכרת על ידי האיחוד האירופי כמדינה בעלת הגנת פרטיות נאותה (Adequacy Decision, 2011). העברות לארה"ב מוסדרות דרך SCCs.
